# vahid-mahbobifard

## سایت کناف کرج (KNAUF KARAJ)

وب‌سایت فارسی و راست‌چین کناف کرج: فروشگاه آنلاین مصالح و تجهیزات کناف، خدمات اجرای سقف کاذب و
دیوار خشک، فرم استعلام اجرای پروژه با کد پیگیری و پنل مدیریت کامل.

| بخش | مسیر | توضیح |
| --- | --- | --- |
| وب | `web/` | React 19 + Vite (راست‌چین، فونت Vazirmatn، طراحی مشکی/طلایی) |
| API | `api/` | Express 5 + SQLite (better-sqlite3) — فروشگاه، سفارش‌ها، درخواست‌ها، احراز هویت مدیر |
| تصاویر نمایشی | `web/public/images/` | تصاویر SVG تولیدشده با اجرای `scripts/generate-placeholders.mjs` |

### معماری

- تمام تماس‌های مرورگر با همان مبدأ (`/api`) انجام می‌شود؛ سرور توسعه Vite درخواست‌ها را به سرویس API
  پروکسی می‌کند تا کوکی نشست مدیر first-party بماند و نیازی به CORS نباشد.
- **مبلغ سفارش فقط در سرور محاسبه می‌شود.** مرورگر تنها شناسه و تعداد محصول را می‌فرستد
  (`POST /api/orders`); قیمت، تخفیف و هزینه ارسال از پایگاه داده خوانده می‌شود.
- داده‌ها در SQLite داخل والیوم `app_data` نگهداری می‌شود (خارج از گیت) و همه فایل‌های حساس
  (پیوست درخواست‌ها، نشست‌ها) بیرون از مسیر عمومی قرار دارند.
- موجودیت‌های اصلی: `products`, `categories`, `services`, `portfolio_items`, `orders`,
  `project_requests`, `wholesale_requests`, `reviews`, `faqs`, `pages`, `settings`, `users`,
  `activity_log`.

### اجرا در محیط توسعه

```bash
docker compose --project-name app --project-directory "$BASE44_PROJECT_ROOT" \
  -f "$BASE44_PROJECT_ROOT/docker-compose.base44.yml" up -d --build
```

- وب: <http://localhost:3000> — API: <http://localhost:8000/api/health>
- سرویس `seed` یک‌بار اجرا می‌شود و داده‌های پایه را می‌سازد؛ در اجراهای بعدی هیچ رکوردی بازنویسی
  نمی‌شود، بنابراین تغییرات مدیر در پنل باقی می‌ماند.

### ورود مدیر

- نشانی پنل: `/admin/login` (پنل مدیریت: `/admin`)
- نام کاربری پیش‌فرض: `admin` — رمز عبور پیش‌فرض توسعه در `.env.base44-defaults` تعریف شده است.
- این رمز فقط برای محیط توسعه است. در پنل مدیریت → «تنظیمات» → «تغییر رمز عبور مدیر» آن را عوض کنید،
  یا مقدار `ADMIN_PASSWORD` را در بخش Secrets همین محیط وارد کنید (فایل `/run/base44/app.env` بر
  `.env.base44-defaults` اولویت دارد).

### موارد نیازمند تکمیل توسط مدیر (هیچ مقدار ساختگی در سایت منتشر نشده است)

- **اطلاعات تماس**: شماره تماس، واتساپ، نشانی، ایمیل و ساعات کاری → «تنظیمات». تا ثبت شماره، دکمه‌های
  تماس و واتساپ نمایش داده نمی‌شوند.
- **قیمت محصولات**: هر ۲۴ محصول با وضعیت «قیمت ثبت نشده» منتشر شده‌اند و خرید آن‌ها غیرفعال است؛
  قیمت باید در «محصولات» ثبت شود.
- **درگاه پرداخت**: پرداخت آنلاین خاموش است. تا اتصال درگاه، سفارش‌ها با وضعیت «پرداخت‌نشده» ثبت
  می‌شوند و هیچ پرداخت موفقی جعل نمی‌شود.
- **دامنه و سئو**: نشانی دامنه در «تنظیمات → سئو» برای ساخت لینک کانونیکال و `sitemap.xml`.
- **نمونه‌کارها و نظرات**: نمونه‌کارهای فعلی تصویر نمایشی («نمونه طراحی») هستند و بخش نظرات تا ثبت
  نظر واقعی پیام «به‌زودی» نشان می‌دهد. نظرهای ارسالی کاربران تا تأیید مدیر منتشر نمی‌شوند.
- **تصاویر واقعی**: تصاویر فعلی، تصاویر نمایشی SVG با پالت برند هستند و از پنل مدیریت با آپلود فایل
  یا نشانی تصویر قابل جایگزینی‌اند.
